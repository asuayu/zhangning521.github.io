# 课间与我们

面向 `https://zhangning521.github.io/` 的 GitHub Pages 工程。默认显示教学工作台，可以切换到“我们的生活”和原来的樱花音乐相册。

## 页面与扩展

- `index.html`：统一入口与页面切换。
- `workbench.html`：迁移自本机教学工作台，保留课表、空闲时段折叠、课程修正、报销路线、默认 150 元、调休申请标记、CSV 导出。
- `together.html` / `together.js` / `together.css`：照片墙、纪念日、回忆手记、一起的小计划、随机相处灵感、Markdown 回忆录、可断网打开的回忆页。
- `album.html`：旧首页原样保留，仅增加返回工作台链接；原照片、音乐、配置与 CSS 路径保留。

增加新页面时，在 `index.html` 的 `pages` 和导航中注册一个相对地址即可。以后可扩展旅行地图、双人小游戏、语音收藏等。

## 本机数据与迁移

公开仓库不包含学生课表、报销记录、飞书账号或新增生活照片。工作台记录保存于当前浏览器的 localStorage，生活记录和照片保存于 IndexedDB。不同设备不会自动同步，请导出/导入备份。

1. 双击 `准备工作台迁移.cmd`，或运行 `node tools/prepare-migration.cjs [原工作台文件夹]`。
2. 得到 `private-export/workbench.personal.json`，其中包含原课程识别配置、安排、修改、路线和标记，不包含 CalDAV 密码。
3. 在在线工作台中打开“日历与数据”，选择该文件导入。
4. 更新飞书日历时，仍先在原本机工作台同步，然后重新生成迁移文件再导入。GitHub Pages 不能运行原 Python 同步服务。

个人迁移文件已被 `.gitignore` 排除，**不要强制加入 Git**。清理浏览器、无痕模式、换域名或设备可能使本机数据不可用，请定期导出备份。原相册中的照片此前已在公开站点上；新增生活照片不会自动上传。

## 本地预览与检查

运行 `本地预览.cmd`，打开 `http://127.0.0.1:18720/`。检查命令：`node tools/check.cjs`。

重新从本机工作台生成网页时：`python tools/build-workbench.py --source "原页面绝对路径"`。生成器会去除源页面中的样例与私密课程名、飞书连接和 localhost 网络调用。

## 发布与还原

目标旧站已核实由 `main` 分支发布，当前线上旧首页对应提交 `7793ba590db34c53e23577dc3464a82d33e037d5`。本项目以该提交为基础；发布时将修改合并到同一仓库的 `main`，保留原 Pages 配置。`.nojekyll` 用于直接发布静态文件。

若要恢复旧首页，可将 `album.html` 复制回 `index.html`，或恢复旧提交中的 `index.html`；旧站媒体文件保持原路径。

本项目按用户选择提供“网页在线、数据在各自浏览器”的模式，没有后台自动飞书同步或跨设备数据库。
